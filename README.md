## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled together with a universal loader. It provides centralized access to Volt, Synapse Z, Potassium, Wave, and xcutorsLoader from a single package.

### Which operating systems are supported?

XCutors is designed exclusively for Windows desktop operating systems. Windows 10 and Windows 11 are fully supported. macOS and Linux are not supported.

### Do I need to install each executor separately?

No. All executor files are included in the package. The universal loader (xcutorsLoader) manages everything in one place, though you may configure individual executors within the loader interface.

### Is XCutors free to use?

XCutors itself is free to download from the official GitHub repository. However, some individual executors included in the package may have their own licensing or access requirements as defined by their respective developers.

### The executor is not injecting. What should I do?

Make sure Roblox is running and fully loaded in a game before attempting to inject. Run the executor as administrator, temporarily disable anticomponent software if it interferes, and ensure you are using the latest version of XCutors compatible with the current Roblox update.

### How do I add my own scripts?

You can add scripts by placing .lua files into the 'Scripts' folder within the XCutors directory. You can also use the built-in file browser or script editor within the executor interface to load, save, and manage scripts.

### How do I update XCutors?

The built-in auto-update feature will notify you when a new version is available. You can also manually check for updates by visiting the GitHub Releases page and downloading the latest version. Simply replace the old files with the new ones.

### Is it safe to use?

Always download XCutors exclusively from the official GitHub repository. Scan downloaded files with your preferred anticomponent software before use. The source files are transparent and available for review on the repository.

### Can I use multiple executors at the same time?

It is recommended to use only one executor per Roblox session to avoid conflicts or instability. The universal loader allows you to switch between executors easily without restarting the entire application.

### Where can I find scripts to use?

XCutors includes a built-in script hub with categorized and popular scripts. You can also find community-shared scripts on various Roblox scripting forums and repositories. Always review scripts before execution.
